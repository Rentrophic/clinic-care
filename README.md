# Clinic Care WordPress Theme

A clean, mobile-first WordPress theme for medical clinics, designed to work with the [Clinic Portal](https://github.com/Rentrophic/clinic-portal) plugin. It uses clinical blues and calming teals, high contrast text, and an accessible layout.

## Features

- Front page, page, single post, and 404 templates
- Header and footer templates
- Responsive layout for phones and desktops

## Installation

1. Copy the `clinic-care` folder into `wp-content/themes/`.
2. In WordPress, go to Appearance, then Themes, and activate **Clinic Care**.
3. Install the Clinic Portal plugin for the clinic features.

Used in the [CareWell Medical Clinic](https://github.com/Rentrophic/carewell) website.
